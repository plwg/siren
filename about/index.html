Siren Open the editor

A Mermaid diagram editor that keeps your diagrams to yourself

Type Mermaid on one side and see the diagram on the other. Share it as a link or a QR code, or paste it into a document as an image. Everything happens in your browser.

What you can do

  • Write and preview. The diagram redraws as you type. Line numbers and a marked error line show where a syntax error is.
  • Share by link. The diagram is compressed into the link itself, so anyone with the link sees it. A view link shows only the diagram, in the theme you chose, with a button to open it in the editor.
  • Share by QR code. Scan the code with a phone to open the diagram there, or download it as a PNG for slides and print.
  • Put it in a document. Copy the diagram as an image, or download SVG or PNG, in light or dark colors with a clear or solid background. Exports use Arial, so text fits in any document app.
  • Start quickly. Begin from an example for each common diagram type, or reopen one of your recent diagrams.
  • Read it your way. Three themes: Sail (light), Deep (dark) and Lighthouse (high contrast), or Auto to follow your system.

Every Mermaid diagram type

Siren draws diagrams with Pele, which supports every diagram type built into Mermaid 12.1.0, including:

  • Flowchart
  • Sequence
  • Class
  • State
  • Entity relationship
  • Gantt
  • Pie
  • Mindmap
  • Timeline
  • Git graph
  • User journey
  • Quadrant chart
  • XY chart
  • Sankey
  • Architecture
  • Block
  • Packet
  • Requirement
  • C4
  • Kanban

Private by design

  • Your diagram lives in the part of the link after #, which browsers never send to a server. Siren has no accounts, no analytics and no tracking.
  • Images inside a shared diagram aren't loaded, so a link can't reveal who opened it.
  • Links inside a diagram show where they really go and ask before opening.
  • Recent diagrams are kept only in your browser, and you can clear them at any time.

Works offline

Once Siren has loaded, it needs no network. Every diagram type, the QR code and exports are part of the page, so you can keep working on a plane or a patchy connection.

Tips

  • Click Siren in the editor's header for a blank diagram. Your browser's Back button returns to the one before.
  • Paste a fenced ```mermaid block from GitHub or a chat, and Siren keeps just the diagram.
  • On a wide screen, drag the divider between the editor and the diagram, or focus it and use the arrow keys. Double-click resets it.
  • Add ?theme=light, dark or contrast to a link to choose how it looks.
